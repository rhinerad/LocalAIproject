Local Agent Harness

The harness is everything wrapped around the model: what it's shown, which model gets the turn, what happens to its tool calls, and what is checked before its reply reaches you. Current as of October 21, 2026.

Tool profiles: what the model is allowed to see

Step 1 picks a profile on every hop. The model can only call tools in that profile, which keeps small models from getting lost in the full catalog.

What changed in the harness on Oct 20–21

  • Turn start: a character named in an image or video request gets their face and files attached (asset_library).
  • Shortcut layer: long tasks no longer trip the list-folder route. Naming a tool skips every shortcut. Blender runs only when you ask for it. Story scenes go to the shot pipeline.
  • Tool seam: missing or wrong pictures are filled by character name, and the pictures each tool returns are remembered for the chat.
  • Reply guards: auto-render is on, so a plan goes live without asking. A reply that claims files with no job behind it is replaced.
  • After the turn: job_watch posts finished jobs into their chat and marks it unread.
